Disease, in resolution

Resolution is the whole game.

Every important disagreement in this field reduces to resolution: how finely you can see, at which scale, under what intervention. Bulk gave way to single-cell; single-cell is giving way to spatial; spatial gives way to tissue dynamics. We are building for the next step, not the current one.

The thesis

Each column is a voice. Each voxel is a cell, in a place, at a time.

A simulation is only as useful as its smallest honest unit. We model tissue as a field of cells with position, state and coupling — high enough resolution that a perturbation has somewhere to propagate, coarse enough that it can be run often enough to learn from.

Four commitments
01

Multimodal

Six channels, one latent state. Resolution in modality, not just in space.

02

Multi-scale

Molecular, cellular, neighbourhood, tissue — four resolutions, one set of weights.

03

Causal

Perturbation-conditioned, so the model predicts intervention outcomes rather than ranking correlations.

04

Mechanistic

Pathway-level attribution on every call, because an unexplained prediction cannot be acted on.

What we are building
Substrate

The virtual tissue

Cells as voxels of a simulation: position, state, coupling and time. Perturb it a thousand times for the cost of one experiment.

Discovery

Target discovery at depth

Multi-omics target discovery read out of simulated tissue response, with the mechanism attached and the uncertainty stated.

Compute

Built to be run often

The value comes from iteration count. Everything is designed around how many perturbations we can afford to simulate per day.
